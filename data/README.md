# Справочник контента

Наполнение портала хранится здесь в JSON, а не только в базе данных. Так его
можно читать и править в редакторе, проверять скриптом и восстанавливать базу
одной командой:

```bash
python sources/manage.py seed_demo          # добавить/обновить
python sources/manage.py seed_demo --flush  # полностью пересобрать
python tools/check_data.py                  # проверить перед загрузкой
```

Загрузка идемпотентна: записи ищутся по `slug` (у пользователей — по
`username`) и обновляются, а не дублируются.

## Файлы

| Файл | Что содержит | Ключ |
|---|---|---|
| `villages.json` | сёла округа | `slug` |
| `categories.json` | категории объектов | `slug` |
| `attractions.json` | туристические объекты | `slug` |
| `events.json` | события календаря | `slug` |
| `routes.json` | маршруты и их точки | `slug` |
| `demo_users.json` | демонстрационные учётные записи | `username` |
| `reviews.json` | отзывы (часть — на модерации) | `user` + `attraction` |

## Поля, о которых стоит знать

**`status`** у объекта — `active`, `construction`, `planned`, `closed`.
Портал показывает статус прямо на карточке. Всё, кроме `active`, обязано
сопровождаться пояснением в `fact_note` — это проверяет `tools/check_data.py`.

**`in_district`** — находится ли объект в границах Благовещенского округа.
Объекты со значением `false` выводятся отдельным блоком «Рядом с округом» и
не могут входить в маршруты округа (тоже проверяется).

**`is_fictional`** — название и услуги придуманы для учебной демонстрации.
Такие карточки помечаются на сайте значком «Учебные данные».

**Даты событий** заданы как `month` + `day` + `days`, а не абсолютной датой.
При загрузке команда `seed_demo` подставляет ближайшее наступление этой даты
(в текущем или следующем году), поэтому демонстрационный календарь не
устаревает и на защите всегда показывает предстоящие события.

## Достоверность данных

- Названия сёл и публичных объектов (мост, пункт пропуска, памятник казакам,
  аэропорт) — реальные, сведения о них публичные.
- Названия баз отдыха, усадеб, пасеки и фермерского хозяйства, помеченные
  `is_fictional: true`, — условные образцы. Перед любым практическим
  использованием их нужно заменить на реальные и сверить с реестром объектов
  туриндустрии.
- **Координаты приблизительные.** Они привязаны к населённым пунктам и
  годятся, чтобы понять географию округа, но не для навигации по GPS.
  Перед публикацией координаты нужно уточнить по карте.
- Английские и китайские названия сёл — транслитерации, подготовленные для
  учебной демонстрации; для реального портала их следует согласовать.
- Фактические оговорки по спорным объектам собраны в
  [`docs/08-facts.md`](../docs/08-facts.md).

## Фотографии

В репозитории фотографий нет: права на снимки объектов не оформлялись.
Команда `seed_demo` генерирует абстрактные изображения-заглушки в цвете
категории (Pillow) и кладёт их в `sources/media/`, которая не отслеживается
git. Настоящие фотографии загружаются через панель управления, в карточку
объекта.
