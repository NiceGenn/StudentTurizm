# Руководство пользователя

## Что можно делать без регистрации

Гостю доступно всё содержимое портала: каталог объектов, карта, календарь
событий, маршруты, страницы сёл и справочные страницы. Регистрация нужна
только для избранного и отзывов.

## Поиск объекта

1. Откройте **Каталог** в верхнем меню.
2. Задайте условия в панели фильтров:
   - **Поиск** — по названию, описанию и тегам (например, «баня», «журавли»);
   - **Категория** — базы отдыха, природа, история, приграничье, агротуризм,
     событийные площадки;
   - **Село** — один из населённых пунктов округа;
   - **Сезон** — круглый год, лето, зима, весна и осень;
   - **Сортировка** — по названию, по рейтингу, сначала новые.
3. Нажмите **Показать**. Кнопка **Сбросить** возвращает полный список.

Внизу страницы отдельным блоком идёт раздел **«Рядом с округом»** — объекты
регионального контекста, которые расположены за границами округа.

## Как читать метки на карточке

| Метка | Значение |
|---|---|
| «Круглый год», «Лето», «Зима», «Весна и осень» | сезон, когда объект интересен |
| 🏗 **Строится** | объект ещё не открыт, сроки могут сдвигаться |
| 📅 **Планируется** | объекта пока нет, есть только планы |
| ⛔ **Не действует** | ехать нельзя: карточка оставлена как предупреждение |
| 📍 **Рядом с округом** | объект за границами округа |
| ✎ **Учебные данные** | название и услуги условные, это учебный образец |
| ★ 4.5 (2) | средняя оценка по одобренным отзывам и их количество |

Отсутствие метки статуса означает, что объект действующий.

## Карта

Раздел **Карта** показывает все объекты сразу. Нажатие на маркер открывает
подсказку с названием, селом и ссылкой на карточку. Слева отмечаются
категории: снимите отметку — маркеры этой категории скроются.

Координаты в учебной базе приблизительные: их достаточно, чтобы понять,
в каком селе находится объект, но не для навигации по GPS.

## Маршруты

Раздел **Маршруты** содержит готовые поездки. На странице маршрута есть:

- длительность, сезон и сложность;
- **Программа** — точки по порядку с комментарием к каждой;
- карта с пронумерованными точками. Линия между ними показывает
  последовательность, а не реальную дорогу.

Любую точку можно сохранить в избранное кнопкой ♥ прямо из программы.

## Календарь событий

Раздел **События** по умолчанию показывает предстоящие события. Можно
отфильтровать по месяцу и селу или отметить «Показать прошедшие».
Если у события указана площадка, со страницы события есть переход на
карточку объекта.

## Регистрация и вход

1. Нажмите **Регистрация** в шапке.
2. Заполните имя пользователя, имя, фамилию, почту и пароль дважды.
3. После отправки формы вы сразу войдёте на портал.

Пароль должен быть не короче 8 символов, не состоять только из цифр и не
совпадать с именем пользователя — это стандартные проверки Django.

> Портал учебный. Не вводите настоящие персональные данные.

## Избранное

Кнопка ♥ есть на карточке в каталоге, на странице объекта и в программе
маршрута. Нажатие добавляет объект в избранное, повторное нажатие убирает.
Список открывается по ссылке **♥ Избранное** в шапке.

## Отзывы

На странице объекта, если вы вошли, доступна форма отзыва:

1. Выберите оценку от 1 до 5.
2. Напишите текст — не менее 20 символов.
3. Нажмите **Отправить**.

Отзыв уходит на модерацию и появляется на сайте после проверки. Пока он не
одобрен, в личном кабинете он помечен «на модерации». Об одном объекте
можно оставить один отзыв.

## Смена языка

Переключатель языков находится в шапке: **Русский**, **English**, **中文**.
Выбор сохраняется на время сессии и действует на всех страницах. Если у
объекта нет перевода какого-то поля, показывается русский вариант — так
страница не остаётся пустой.

## Личный кабинет

Меню с вашим именем → **Профиль**. Здесь можно изменить имя, фамилию и
почту, посмотреть количество сохранённых объектов и список своих отзывов с
их статусом.

## Что делать, если

**Карта не загрузилась.** Тайлы карты приходят с серверов OpenStreetMap:
проверьте подключение к интернету. Список объектов при этом работает и без
карты.

**Не приходит подтверждение регистрации.** Портал учебный, письма не
отправляются: аккаунт активен сразу.

**Отзыв не появился.** Он ждёт модерации. Проверьте его статус в профиле.

**В карточке ошибка или объект закрылся.** Напишите на адрес со страницы
«Контакты» — контент-менеджер внесёт правку.
