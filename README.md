# Туристический портал Благовещенского муниципального округа

Учебный веб-проект: каталог туристических объектов, карта, календарь
событий и готовые маршруты Благовещенского муниципального округа Амурской
области — на русском, английском и китайском языках.

**Стек:** Python 3.11+, Django 5.1, PostgreSQL или SQLite, Bootstrap 5,
Leaflet + OpenStreetMap.

> Проект учебный. Пользователи и их данные вымышленные, интеграций с
> государственными системами нет, бронирования и платежи не выполняются.
> Названия сёл и публичных объектов реальные; часть коммерческих карточек —
> условные образцы, помеченные в интерфейсе. Подробности — в
> [docs/08-facts.md](docs/08-facts.md).

## Быстрый старт

```bash
git clone https://github.com/NiceGenn/StudentTurizm.git
cd StudentTurizm
./tools/setup.sh     # окружение, зависимости, миграции, демо-контент
./tools/run.sh       # http://127.0.0.1:8000/
```

Панель управления — <http://127.0.0.1:8000/admin/>, вход `admin` /
`admin12345` (учебный пароль, сменить при любом реальном развёртывании).

Вручную, без скриптов:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r sources/requirements.txt
python sources/manage.py migrate
python sources/manage.py seed_demo
python sources/manage.py runserver
```

## Что умеет портал

- **Каталог** объектов с фильтрами по категории, селу и сезону, поиском по
  названию, описанию и тегам и тремя вариантами сортировки.
- **Карта** на Leaflet и OpenStreetMap: маркеры в цветах категорий,
  подсказки, переход в карточку, скрытие категорий.
- **Календарь событий** с фильтрами по месяцу и селу.
- **Готовые маршруты**: программа по шагам и точки на карте в порядке
  следования.
- **Личный кабинет**: регистрация, избранное, отзывы с оценкой.
- **Модерация**: отзыв публикуется только после одобрения.
- **Панель контент-менеджера** на базе админки Django.
- **Три языка**: русский, английский, китайский — и интерфейс, и контент.
- **Статусы объектов**: «действующий», «строится», «планируется», «не
  действует» плюс признаки «рядом с округом» и «учебные данные». Это защищает
  туриста от поездки по устаревшей информации — см.
  [docs/08-facts.md](docs/08-facts.md).

## Структура репозитория

```
data/       справочник контента в JSON + описание полей
docs/       документация практики: ТЗ, диаграммы, тест-кейсы, руководства
releases/   выгрузки готовых версий
sources/    исходный код Django-проекта
  portal/     настройки, маршрутизация
  catalog/    модели, представления, админка, команда наполнения
  accounts/   регистрация, профиль, избранное
  templates/  шаблоны
  static/     стили, скрипты карты, локальные копии библиотек
  locale/     переводы интерфейса (ru → en, zh_Hans)
tools/      скрипты установки, запуска, проверки, подготовки к офлайну
```

## Команды

| Команда | Назначение |
|---|---|
| `./tools/setup.sh` | первичная настройка проекта |
| `./tools/run.sh` | сервер разработки |
| `./tools/test.sh` | валидация справочника, системные проверки, 34 теста |
| `./tools/vendor_assets.sh` | скачать Bootstrap и Leaflet для работы без интернета |
| `python tools/check_data.py` | проверить `data/*.json` до загрузки в базу |
| `python sources/manage.py seed_demo` | загрузить или обновить демо-контент |
| `python sources/manage.py seed_demo --flush` | пересобрать контент с нуля |

## База данных

По умолчанию — SQLite, чтобы проект запускался сразу после клонирования.
Целевая СУБД по ТЗ — PostgreSQL, переход делается переменными окружения:

```bash
export DB_ENGINE=postgres DB_NAME=turizm DB_USER=turizm DB_PASSWORD=...
pip install "psycopg[binary]"
python sources/manage.py migrate && python sources/manage.py seed_demo
```

- Картографическая основа — [OpenStreetMap](https://www.openstreetmap.org/copyright),
  лицензия ODbL, атрибуция выводится на каждой карте.
- Библиотеки: [Django](https://www.djangoproject.com/) (BSD),
  [Bootstrap](https://getbootstrap.com/) (MIT), [Leaflet](https://leafletjs.com/) (BSD).
- Фотографий объектов в репозитории нет: команда наполнения генерирует
  абстрактные заглушки, настоящие снимки загружаются через панель управления.
