# Заметки для работы над проектом

Учебный туристический портал Благовещенского муниципального округа.
Django 5.1, Bootstrap 5, Leaflet + OpenStreetMap.

## Как устроен репозиторий

- `sources/` — код Django-проекта. Приложения: `catalog` (контент, карта,
  маршруты, события, отзывы, избранное) и `accounts` (регистрация, профиль).
- `data/` — справочник контента в JSON. Это **источник истины** для
  демонстрационного наполнения; база собирается из него командой `seed_demo`.
- `docs/` — документация практики.
- `tools/` — скрипты установки, запуска, проверки.
- `releases/` — выгрузки готовых версий.

## Обязательное перед коммитом

```bash
./tools/test.sh
```

Скрипт делает четыре вещи: валидирует `data/*.json`, запускает системные
проверки Django, убеждается, что модели и миграции синхронны, и прогоняет
34 теста. Все четыре должны быть зелёными.

## Правила, которые легко нарушить

**Контент правится в `data/*.json`, а не только в базе.** Правка через
админку живёт в локальной базе и потеряется при `seed_demo --flush`.
Массовые изменения вносите в JSON и применяйте командой наполнения.

**Статусы обязательны.** Объект со статусом `construction`, `planned` или
`closed`, а также помеченный `is_fictional`, обязан иметь непустой
`fact_note`. Это проверяет `tools/check_data.py` и это ключевое требование
проекта: портал не должен вводить туриста в заблуждение.
Фактические оговорки собраны в `docs/08-facts.md` — при правке спорных
объектов обновляйте и его.

**Маршруты только из действующих объектов округа.** Недействующие объекты и
объекты с `in_district: false` в маршруты включать нельзя (тоже проверяется
валидатором).

**Три языка.** Новые тексты интерфейса оборачивайте в `{% translate %}` /
`gettext_lazy`, затем `makemessages` → перевод → `compilemessages`.
У моделей переводимые поля дублируются суффиксами `_en` и `_zh`; в шаблонах
используйте свойства `*_i18n` (`title_i18n`, `description_i18n`), которые
откатываются на русский при пустом переводе.

**Публичные представления фильтруют по `is_published`.** Для выборок
используйте `Attraction.objects.published()` и `.with_rating()` — последний
считает рейтинг одним запросом вместо запроса на карточку.

## Стиль

- Комментарии и строки интерфейса — по-русски, имена в коде — по-английски.
- `verbose_name` у всех полей моделей: они видны контент-менеджеру в админке.
- Отступ 4 пробела в Python, 2 — в HTML, CSS, JS и JSON.
- Новые зависимости добавлять только при явной необходимости: проект должен
  ставиться из `Django` и `Pillow`.

## Чего в проекте нет и не должно появиться

Интеграций с государственными системами, реальных платежей и бронирований,
настоящих персональных данных. Это учебный проект, и дисклеймер об этом
выводится в подвале каждой страницы.
