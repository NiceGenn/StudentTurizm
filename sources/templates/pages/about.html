{% translate "О портале" %}

{% blocktranslate %}Портал собирает в одном месте туристическое предложение Благовещенского муниципального округа Амурской области: базы отдыха и гостевые дома в сёлах, приграничные смотровые точки, памятники казачьей истории, природные места поймы Амура и Зеи, фермы и пасеки, а также события и готовые маршруты.{% endblocktranslate %}

{% blocktranslate %}Задача простая: сегодня сведения об объектах разбросаны по справочникам, областным сайтам и социальным сетям, поэтому гостю трудно за один заход понять, что в округе вообще есть. Портал даёт каталог с фильтрами, карту, календарь событий и маршруты — и делает это на трёх языках, включая китайский, потому что округ примыкает к границе и к мостовому переходу в Хэйхэ.{% endblocktranslate %}

{% translate "Что здесь есть" %}

  • {% translate "Каталог объектов с фильтрами по категории, селу и сезону" %}
  • {% translate "Карта на Leaflet и OpenStreetMap с маркерами по категориям" %}
  • {% translate "Календарь событий с фильтром по месяцу и селу" %}
  • {% translate "Готовые маршруты с последовательностью точек" %}
  • {% translate "Избранное и отзывы для зарегистрированных пользователей" %}
  • {% translate "Русская, английская и китайская версии интерфейса" %}

{% translate "Как мы обозначаем статусы" %}

{% blocktranslate %}Не всё, о чём пишут в интернете, работает на самом деле. Поэтому у каждого объекта есть статус, и он виден прямо на карточке.{% endblocktranslate %}

  • {% translate "Действующий" %} — {% translate "объект принимает гостей" %}
  • 🏗 {% translate "Строится" %} — {% translate "объект ещё не открыт, сроки могут сдвигаться" %}
  • ⛔ {% translate "Не действует" %} — {% translate "поездку планировать нельзя" %}
  • 📍 {% translate "Рядом с округом" %} — {% translate "объект за границами округа, приведён для контекста" %}
  • ✎ {% translate "Учебные данные" %} — {% translate "название и услуги условные" %}
{% translate "Дисклеймер." %} {% blocktranslate %}Это учебный проект. Пользователи и их данные вымышленные, интеграций с государственными системами нет, бронирования и оплаты не производятся. Названия сёл и публичных объектов реальные, часть коммерческих карточек — условные образцы. Перед практическим использованием сведения нужно сверить с актуальными источниками.{% endblocktranslate %}
